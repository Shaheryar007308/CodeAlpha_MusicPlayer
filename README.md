# CodeAlpha_MusicPlayer
Music Player
This project is a Music Player Web Application developed using HTML, CSS, and JavaScript as part of my internship tasks. It allows users to play, pause, skip to next or previous tracks, control volume, and view song details such as title, artist, duration, and progress. The player includes a progress bar for seeking within the song and supports a playlist with autoplay functionality. The main goal of this project is to understand JavaScript event handling, audio controls, and DOM manipulation while building an interactive and responsive user interface.
